# GitHub profile setup guide

Follow these steps to make your GitHub profile look professional.

---

## Step 1 — Publish your profile README

1. Go to [github.com/new](https://github.com/new)
2. **Repository name:** `veerendrakalyanbabu-VKB` (must match your username exactly)
3. Set to **Public**
4. Check **Add a README file**
5. Click **Create repository**
6. Replace the README content with the file from:

```text
profile/README.md
```

7. Update placeholders:
   - LinkedIn URL
   - Email address
   - Recruitment Analytics repo link (when published)
